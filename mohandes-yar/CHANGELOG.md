# تغییرات مهندس‌یار برق

## نسخه 0.4 — ۷ نوامبر ۲۰۲۶
- افزودن دریافت نسخه پشتیبان JSON از پروژه‌های ذخیره‌شده.
- افزودن بازیابی و ادغام پروژه‌ها از فایل پشتیبان.
- اعتبارسنجی ساختار فایل، تعداد رکوردها، اندازه فایل و فیلدهای اصلی پیش از ذخیره.
- نمایش پیام موفقیت/خطا و هشدار درباره رمزنگاری‌نشدن فایل پشتیبان.
- حفظ سیاست عدم پیشنهاد سطح مقطع کابل یا تجهیزات حفاظتی بدون داده مرجع معتبر.

## محدودیت‌های پابرجا
- ذخیره‌سازی همچنان محلی و وابسته به مرورگر است؛ همگام‌سازی ابری و ورود کاربر وجود ندارد.
- محاسبه افت ولتاژ ساده‌شده است و برای تأیید طراحی نهایی کافی نیست.
- بانک بندها و جداول رسمی مبحث ۱۳ و نشریات ۱۱۰ هنوز به‌صورت قابل استناد و آزمون‌شده در موتور پیاده نشده است.
- انتشار موفق GitHub Pages و نتیجه اجرای CI باید جداگانه بررسی شوند.
