# مهندس‌یار برق

نسخه آزمایشی MVP برای محاسبات مقدماتی برق ساختمان. رابط فارسی و راست‌چین است و برای اجرای آنلاین به سرویس سمت سرور نیاز ندارد.

## شروع سریع
1. صفحه [مهندس‌یار برق](https://shahramnaderian.github.io/mohandes-yar/) را باز کنید.
2. از «پروژه جدید» مشخصات پروژه را ثبت کنید.
3. ابزارهای بار و دیماند، جریان و توان، افت ولتاژ و متره را از منو انتخاب کنید.
4. برای چاپ، از دکمه چاپ مرورگر استفاده کنید.

## داده و حریم خصوصی
- پروژه‌ها در localStorage همان مرورگر و همان دستگاه ذخیره می‌شوند.
- در این نسخه حساب کاربری، همگام‌سازی ابری، پشتیبان‌گیری خودکار یا رمزنگاری داده‌ها وجود ندارد.
- پاک‌کردن داده‌های سایت در مرورگر می‌تواند پروژه‌های ذخیره‌شده را حذف کند. از اطلاعات محرمانه در نسخه عمومی استفاده نکنید.

## موتور محاسباتی
توابع قطعی و مستقل در `core.js` قرار دارند:
- جریان از توان برای تک‌فاز و سه‌فاز
- توان از جریان
- دیماند بر اساس ضریب هم‌زمانی ورودی کاربر
- افت ولتاژ مقاومتی مقدماتی
- متره رشته کابل با درصد پرت

افت ولتاژ یک مدل مقاومتی ساده است؛ راکتانس، دمای واقعی هادی، هارمونیک، شرایط راه‌اندازی و دیگر عوامل طراحی در آن کامل لحاظ نشده‌اند. این ابزار برای انتخاب نهایی کابل، کلید، فیوز، ظرفیت انشعاب یا تأیید طراحی کافی نیست.

## آزمون‌ها
نیازمند Node.js نسخه 18 یا جدیدتر:
```bash
npm test
```
آزمون‌ها با ماژول داخلی `node:test` اجرا می‌شوند.

## وضعیت انطباق مقررات
این نسخه تأییدیه انطباق کامل با مبحث ۱۳ یا نشریات ۱۱۰ ندارد. جداول ظرفیت جریان، ضرایب تصحیح، هماهنگی حفاظتی، اتصال زمین و الزامات بند/جدول هنوز به بانک مرجع نسخه‌دار و بازبینی مهندس واجد صلاحیت نیاز دارند. هیچ سطح مقطع یا وسیله حفاظتی نباید صرفاً بر اساس این MVP انتخاب شود.

## ساختار
- `index.html`: رابط کاربری
- `core.js`: موتور محاسباتی مستقل
- `tests/core.test.js`: آزمون‌های واحد
- `docs/ARCHITECTURE.md`: معماری و نقشه توسعه
- `docs/STANDARDS_REGISTER.md`: دفتر منابع و وضعیت انطباق
